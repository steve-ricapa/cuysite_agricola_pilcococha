# Investigación de Referencias para Fundo Agrícola Pilcococha

## Objetivo
Analizar 6 sitios web de empresas agroexportadoras peruanas e internacionales para definir la estructura, diseño y funcionalidades del sitio web a desarrollar para el fundo "Agricola Pilcococha", dedicado a la venta de palta (aguacate).

---

## 1. Camposol (https://www.camposol.com/)

### Estructura y Contenido
- **Header**: Logo, menú principal con categorías desplegables
- **Menú principal**: Home, About Us, Products, Quality, Social Commitment, Investors, Community, Contact Us
- **Products**: Avocados, Blueberries, Table Grapes, Mangos, Mandarins (cada producto tiene su propia página)
- **Features**: Sustainability Report 2025, Working With Us, Testimonials, Recipes
- **Social media**: Facebook, Instagram, LinkedIn, Youtube visibles en footer
- **Contacto**: Dirección en Lima, Perú +511 634-7100

### Tecnología Observada
- WordPress con tema custom "camposol"
- Imágenes optimizadas, slider de imágenes
- Menú mega con categorías anidadas

### Hallazgos Clave
- Estructura vertical de productos destacados en home
- Sección de sostenibilidad muy importante
- Integración con redes sociales visible
- Catálogo de productos por tipo de fruta

## 2. Peruvian Inka Fruit (https://www.inkafruit.pe/)

### Estructura y Contenido
- **Header**: Logo, menú principal simple
- **Menú principal**: Home, About Us, Fruits, Calendar, Quote
- **Frutas**: Pomegranate, Asparagus, Mango, Avocado, Ginger (cada una con PDF de ficha técnica)
- **Categorías**: About us (planeamiento estratégico, RR.SS), Destinations, Calendar
- **Slogan**: "Fruits from the tree to the palate!"

### Tecnología Observada
- WordPress
- Enlaces a PDFs para ficha técnica de cada fruta
- Calendar visual como imagen

### Hallazgos Clave
- Enfoque en PDFs descargables de ficha técnica
- Menú muy simplificado
- Catálogo de frutas con PDFs específicos
- Mapa de destinos de exportación

## 3. Profrutos Perú (https://www.profrutosperu.pe/)

### Estructura y Contenido
- **Header**: Logo, menú horizontal con categorías
- **Menú principal**: Proceso, Empresa, Productos, Galería, Contactanos, MÁS
- **Productos**: Palta, Mandarina, Uva, Mango (con sub-páginas "copia-de-")
- **Sección destacada**: Imagen principal de palta, galería de 5 imágenes
- **Footer**: Instagram, copyright

### Tecnología Observada
- **Wix** (construido con Wix Editor)
- Estructura de anclas/sections (comp-m8g3jl3f, comp-m8g3jl41, etc.)
- Galerías de imágenes con hover effects

### Hallazgos Clave
- Diseño más visual/imagen-focused
- Sección "PROCESO" prominentemente visible
- Menú sticky o anclado
- Integración con redes sociales (Instagram)

## Patrones Comunes en Sitios Agroexportadores Peruanos

1. **Catálogo de productos por fruta** - Cada tipo de producto (palta, arándano, uva, mango) tiene su propia página/section
2. **Menú de navegación estructurado** - Home, About/Company, Products, Quality/Process, Contact
3. **Información de contacto clara** - Teléfono, dirección, redes sociales
4. **Enfoque en sostenibilidad/calidad** - Reportes, certificaciones, misión-visión
5. **Presencia en redes sociales** - Links a Facebook, Instagram, LinkedIn

---

## Recomendaciones para Agricola Pilcococha

### Estructura de Menú Recomendada
1. **Home** - Hero section con palta destacada, llamado a acción
2. **Nuestra Empresa** - Misión, visión, historia del fundo
3. **Productos** - Catálogo de palta (variedades, calibres, temporada)
4. **Proceso/Calidad** - Fotos del campo, cosecha, empaque, certificaciones
5. **Contacto** - Formulario, dirección, teléfonos, mapa
6. **Blog/Noticias** - Actualizaciones de temporada, recetas, cuidados

### Elementos Visuales Clave
- Hero section con imagen de alta calidad de palta fresca
- Galería de procesos (campo → cosecha → empaque)
- Tarjetas de características nutricionales
- Sección de certificaciones (GLOBALGAP, organic, etc.)
- Formulario de cotización/quote

### Tecnologías Sugeridas
- **Tailwind CSS v4** (como proyecto actual) para styling utility-first
- React para interactividad (formularios, filters de productos)
- Headless CMS para gestionar contenido de productos y noticias
- Integración con Google Maps para ubicación del fundo
